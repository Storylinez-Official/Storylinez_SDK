# How to Use Reference Media in Storylinez - Complete Guide

## Overview

Reference media in Storylinez allows you to guide AI content generation using your own images, videos, or other visual materials. This feature helps ensure that generated content aligns with your vision, brand style, or specific visual requirements.

## What You'll Learn

- Understanding reference media functionality
- How to upload and use reference images
- Best practices for reference media selection
- Integration with storyboard and content generation
- Optimizing reference media for better results

## Prerequisites

- Active Storylinez project
- Reference images or media files ready
- Understanding of basic project workflow
- Familiarity with media upload process

## What is Reference Media?

Reference media serves as visual guidance for AI content generation. When you provide reference images, the AI analyzes them and generates content that matches the style, composition, color palette, or subject matter of your references.

### Use Cases for Reference Media

1. **Style Consistency**: Maintain visual consistency across video scenes
2. **Brand Alignment**: Ensure generated content matches brand aesthetics
3. **Product Focus**: Generate content featuring specific products or elements
4. **Composition Guidance**: Control layout and visual arrangement
5. **Color Matching**: Maintain consistent color schemes

## Step-by-Step Process

### Step 1: Prepare Reference Images

1. **Select High-Quality Images**
   - Use high-resolution images (minimum 1024x1024)
   - Ensure clear, well-lit photos
   - Choose images that clearly show desired elements

2. **Consider Image Content**
   - Focus on images with clear subjects
   - Avoid overly complex or cluttered images
   - Select images that represent your desired outcome

### Step 2: Upload Reference Media

1. **Access Upload Interface**
   - Navigate to your project's media section
   - Look for "Reference Media" or "Upload Reference" options
   - This may be within the prompt or storyboard interface

2. **Upload Process**
   - Drag and drop reference images
   - Or use file browser to select images
   - Multiple reference images can be uploaded

### Step 3: Apply Reference Media to Content Generation

1. **In Prompt Creation**
   - When writing your video prompt, reference uploaded media
   - Specify how the reference should guide generation
   - Use clear descriptions of what elements to match

2. **In Storyboard Development**
   - Reference images can guide scene generation
   - AI analyzes visual elements for style matching
   - Apply references to specific scenes or overall project

### Step 4: Review and Refine

1. **Analyze Generated Content**
   - Compare generated content with reference images
   - Identify elements that match your vision
   - Note areas that need adjustment

2. **Iterate and Improve**
   - Adjust prompts based on reference matching
   - Try different reference images if needed
   - Refine descriptions for better alignment

## Best Practices for Reference Media

### Image Selection Guidelines

1. **Quality Requirements**
   - High resolution and clear focus
   - Good lighting and color accuracy
   - Minimal noise or compression artifacts

2. **Content Considerations**
   - Clear subject matter
   - Appropriate composition
   - Representative of desired outcome

3. **Style Consistency**
   - Similar visual style across references
   - Consistent color palette
   - Matching aesthetic approach

### Effective Reference Usage

1. **Specific Guidance**
   - Use references for specific visual elements
   - Don't rely on references for complex narratives
   - Focus on style, color, and composition

2. **Multiple References**
   - Combine references for different aspects
   - Use one for color, another for composition
   - Avoid conflicting visual styles

3. **Clear Intent**
   - Specify what aspect of the reference to match
   - Describe the desired outcome clearly
   - Provide context for reference usage

## Integration with Project Workflow

### Prompt Enhancement

When using reference media in prompts, be specific about how the reference should guide generation:

```
"Create a product demonstration video in the style of the uploaded reference image. 
Match the lighting, color palette, and modern aesthetic shown in the reference. 
Focus on the clean, minimalist composition style."
```

### Storyboard Alignment

Reference media helps ensure storyboard scenes align with your vision:
- Upload references before storyboard generation
- Review generated scenes against reference materials
- Request regeneration if style doesn't match

### Brand Consistency

Use reference media to maintain brand consistency:
- Upload brand style guides as references
- Include product photos for accurate representation
- Use consistent visual elements across projects

## Technical Considerations

### File Requirements

1. **Supported Formats**
   - PNG, JPG, JPEG for images
   - Standard web-compatible formats
   - Avoid specialized or proprietary formats

2. **Size and Resolution**
   - Minimum 512x512 pixels recommended
   - Maximum file size per upload limits
   - Higher resolution generally provides better results

### Processing and Analysis

1. **AI Analysis Process**
   - System analyzes visual elements automatically
   - Extracts style, color, and composition data
   - Creates guidance parameters for content generation

2. **Processing Time**
   - Reference analysis happens during upload
   - Results are available immediately for use
   - No additional waiting time required

## Troubleshooting Common Issues

### Reference Not Matching Results

**Issue**: Generated content doesn't match reference style
**Solutions**:
- Use higher quality reference images
- Provide more specific descriptions in prompts
- Try multiple references for different aspects
- Ensure reference images are clear and focused

### Poor Quality References

**Issue**: Reference images are low quality or unclear
**Solutions**:
- Use higher resolution source images
- Ensure good lighting in reference photos
- Avoid heavily compressed or noisy images
- Select references with clear subject matter

### Conflicting References

**Issue**: Multiple references provide conflicting guidance
**Solutions**:
- Use references that share similar visual styles
- Focus on specific aspects (color vs. composition)
- Prioritize one reference over others
- Create separate projects for different styles

## Understanding Workflow Dependencies

### Cascade Outdated Markers
When upstream workflow steps change, reference media may show red cascade outdated markers. This indicates the media context has changed.

**Dependency Chain:**
Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render

**Important**: Import tab changes affect ALL downstream tabs, even though Import appears after Prompt visually.

**To resolve cascade outdated markers:**
1. Update all previous workflow tabs first
2. Then refresh your reference media in the current tab
3. This ensures your references work with the latest project data

### Stale Markers
Appear when you change reference media settings but haven't reprocessed:
- Reference analysis parameters
- Style matching settings
- Processing options

**To resolve**: Reprocess your reference media with the new settings
