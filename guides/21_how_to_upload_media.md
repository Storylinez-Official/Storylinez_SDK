## Supported Media Types and Formats

### Images
- **Supported Formats**: PNG, JPG, JPEG
- **Maximum File Size**: 2MB per image
- **Recommended Resolution**: 1920x1080 or higher
- **Use Cases**: Reference images, brand assets, product photos, backgrounds

### Videos
- **Supported Formats**: MP4, MOV, AVI, MKV
- **Maximum File Size**: Varies by subscription plan
- **Recommended Specs**: 1080p, 30fps, H.264 codec
- **Use Cases**: B-roll footage, product demonstrations, testimonials

### Audio
- **Supported Formats**: MP3, WAV, M4A
- **Maximum File Size**: Varies by subscription plan
- **Recommended Quality**: 44.1kHz, 16-bit or higher
- **Use Cases**: Custom voiceovers, background music, sound effects

## Step-by-Step Upload Process

### Method 1: Drag and Drop Upload

1. **Access Media Upload Area**
   - Navigate to your project or media library
   - Look for the upload zone or "Upload Media" button
   - The upload area typically shows a dotted border when active

2. **Drag Files from Computer**
   - Select files from your computer file explorer
   - Drag them directly into the upload zone
   - Multiple files can be uploaded simultaneously

3. **Confirm Upload**
   - Files will appear in the upload queue
   - Verify file names and sizes
   - Click "Upload" or wait for automatic processing

### Method 2: File Browser Upload

1. **Click Upload Button**
   - Find the "Upload" or "Choose Files" button
   - This opens your system's file browser

2. **Select Files**
   - Navigate to your media files
   - Select single or multiple files (Ctrl/Cmd + click)
   - Choose files that meet format requirements

3. **Confirm Selection**
   - Review selected files in the dialog
   - Click "Open" to add to upload queue
   - Proceed with upload process

### Method 3: URL Import (Images Only)

1. **Use URL Import Feature**
   - Look for "Import from URL" option
   - Available for images in certain contexts

2. **Enter Image URL**
   - Paste the direct URL to an image file
   - Ensure the URL points to a supported image format
   - The system will download and process the image

## Troubleshooting Common Issues

### Upload Failures

**"File too large" errors:**
- Check your subscription's file size limits
- Compress the file before uploading
- Consider splitting large files if possible

**"Unsupported format" errors:**
- Verify file format against supported list
- Convert files to supported formats
- Check for file corruption

**"Upload failed" errors:**
- Check internet connection stability
- Try uploading smaller batches of files
- Refresh the page and retry

### Processing Issues

**Files stuck in processing:**
- Wait for automatic completion (may take several minutes)
- Check file integrity and format
- Contact support if processing fails repeatedly

**Poor quality results:**
- Upload higher resolution source files
- Check original file quality
- Review compression settings

**Missing thumbnails or previews:**
- Allow additional time for processing
- Refresh the media library view
- Verify file format compatibility

## Understanding Workflow Dependencies

### Cascade Outdated Markers
When upstream workflow steps change, uploaded media may show red cascade outdated markers. This indicates the media context has changed.

**Dependency Chain:**
Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render

**Important**: Import tab changes affect ALL downstream tabs, even though Import appears after Prompt visually.

**To resolve cascade outdated markers:**
1. Update all previous workflow tabs first
2. Then refresh your media in the current tab
3. This ensures your media works with the latest project data

### Stale Markers
Appear when you change media processing settings but haven't reprocessed:
- AI analysis parameters
- Metadata extraction settings
- Processing options

**To resolve**: Reprocess your media with the new settings
