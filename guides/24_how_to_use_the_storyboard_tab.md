# How to Use the Storyboard Tab on Storylinez

Learn how to create, edit, and manage your video storyboards using Storylinez's powerful storyboard editor.

## What is the Storyboard Tab?

The Storyboard tab is where you:
- Create AI-generated video storyboards from prompts
- Edit and refine individual scenes
- Manage scene timing and transitions
- Preview your video structure before production

## Accessing the Storyboard Tab

1. Open your project in the Project Workflow
2. Navigate to the **Storyboard** tab
3. If no storyboard exists, you'll see the creation interface

## Creating Your First Storyboard

### Basic Creation
1. **Enter your prompt**: Describe the video you want to create
2. **Select target length**: Choose duration (15-120 seconds typically)
3. **Choose voiceover mode**:
   - Generated: AI creates voiceover
   - Skip: No voiceover
   - Upload: Use your own audio file
4. **Configure AI settings**:
   - **Temperature**: Controls creativity (0.1-1.0)
   - **Iterations**: Number of refinement passes
   - **DeepThink**: Enhanced analysis for complex projects
   - **Overdrive**: Maximum quality processing
   - **Web Search**: Include current information
   - **Eco Mode**: Faster, resource-efficient processing

**Important System Features:**
- **Automatic Web Search**: The system automatically searches Google when your content needs current information - no manual control required
- **Built-in Tools**: Calculator and statistical tools activate automatically when relevant to your prompt
- **Smart Processing**: AI decides when to use these features based on your content requirements

### Starting the Generation
1. Click **Generate Storyboard**
2. Monitor progress in the generation status
3. Wait for completion (typically 2-5 minutes)

## Understanding Storyboard Structure

### Scene Components
Each scene contains:
- **Scene Title**: Brief description of what happens
- **Details**: Specific visual and audio instructions
- **Timing**: Duration and transition information
- **Media Assignment**: Which files to use for this scene

### Scene Timeline
- Scenes play sequentially
- Each has defined start and end points
- Transitions connect scenes smoothly
- Total duration matches your target length

## Editing Your Storyboard

### Individual Scene Editing
1. Click on any scene card to open the editor
2. Modify:
   - Scene title and description
   - Timing (in/out points)
   - Visual details
   - Transition effects
3. Save changes to update the storyboard

### Reordering Scenes
1. Use drag-and-drop to reorder scene cards
2. The timeline automatically adjusts
3. Transitions update to maintain flow

### Adding New Scenes
1. Click **Add Scene** button
2. Enter scene details:
   - Title and description
   - Duration
   - Position in sequence
3. The storyboard expands to accommodate new content

### Deleting Scenes
1. Click the delete button on any scene card
2. Confirm the deletion
3. Remaining scenes adjust automatically

## Advanced Storyboard Features

### Media Assignment
- Assign specific uploaded files to scenes
- Use stock media recommendations
- Mix different media types within scenes

### Regeneration Options
1. **Full Regeneration**: Create entirely new storyboard
2. **Partial Regeneration**: Regenerate specific scenes
3. **Prompt Refinement**: Modify with additional instructions

### Settings Adjustment
- Modify AI parameters without full regeneration
- Update target length
- Change voiceover settings
- Adjust processing options

## Storyboard Preview and Review

### Visual Preview
- Scene thumbnails show visual concept
- Timeline displays scene flow
- Duration indicators show timing

### Text Review
- Read through all scene descriptions
- Check for narrative consistency
- Verify technical specifications match requirements

## Working with Storyboard History

### Version Control
- Previous storyboard versions are saved
- Compare different iterations
- Revert to earlier versions if needed

### Change Tracking
- See what modifications were made
- Track regeneration history
- Understand evolution of your concept

## Integration with Other Tabs

### Import Tab Connection
- Media from Import tab becomes available for scene assignment
- Stock media recommendations appear automatically
- Upload additional files as needed

### Edit Tab Preparation
- Completed storyboard feeds into Edit tab
- Scene structure becomes video sequence
- Timing and transitions transfer over

### Voiceover Tab Sync
- Voiceover timing aligns with scene structure
- Generated voiceovers match scene descriptions
- Manual voiceovers can be synchronized

### Understanding Workflow Dependencies
**Cascade Outdated Markers:**
When you modify your storyboard, downstream tabs (Voiceover, Edit, Render) will show cascade outdated markers. This means they're working with old data from your previous storyboard version.

**To resolve cascade outdated markers:**
1. Go to Voiceover tab and click "Update"
2. Then go to Edit tab and click "Update" 
3. Finally go to Render tab and click "Update"
4. Work through the dependency chain in order

**Stale Markers:**
If you change storyboard settings (AI parameters, length, etc.) without regenerating, you'll see a stale marker. Use the chat panel to regenerate your storyboard with the new settings.

## Best Practices

### Prompt Writing
- Be specific about visual style and content
- Include target audience and tone
- Mention key message or call-to-action

### Scene Structure
- Keep scenes focused on single concepts
- Maintain consistent visual style
- Balance dialogue, action, and visual elements

### Timing Considerations
- Allow adequate time for each scene's message
- Consider voiceover pacing
- Plan for smooth transitions between scenes

### Iterative Improvement
- Start with basic storyboard
- Refine specific scenes as needed
- Use regeneration for major changes

## Troubleshooting

### Generation Issues
- Ensure your prompt is clear and specific
- Check that you have sufficient media in Import tab
- Verify AI settings are appropriate for your content

### Editing Problems
- Save changes before navigating away
- Refresh if interface becomes unresponsive
- Check that modifications align with overall narrative

### Performance Optimization
- Use Eco mode for faster processing when testing
- Enable DeepThink only for complex, important projects
- Monitor generation progress and stop if needed

The Storyboard tab is the creative heart of your project, where ideas transform into structured visual narratives ready for production.
