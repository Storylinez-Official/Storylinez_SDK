# How to Create a Project in Storylinez - Step-by-Step Guide

## Overview

Creating a project is the first step to generating AI-powered video content in Storylinez. This guide will walk you through the project creation process, from initial setup to configuring project settings for optimal results.

## What You'll Learn

- How to create a new project
- Understanding project types and orientations
- Setting up project folders and organization
- Configuring initial project settings
- Best practices for project naming and structure

## Prerequisites

- Active Storylinez account
- Organization membership with appropriate permissions
- Basic understanding of the Storylinez interface

## Step-by-Step Project Creation

### Step 1: Access Project Creation

1. **Navigate to Your Dashboard**
   - Log into your Storylinez account at https://app.storylinezads.com
   - Ensure you're in the correct organization using the organization switcher
   - Go to your main dashboard or projects page

2. **Open Project Creation Dialog**
   - Click the "Create Project" or "New Project" button
   - Choose between "Quick Create" for simple projects or "Advanced Create" for detailed configuration

### Step 2: Choose Project Type

**Quick Create (Recommended for beginners):**
- Single prompt-based project creation
- Automatically optimized settings
- Faster setup process

**Advanced Create:**
- Full control over all project settings
- Custom folder organization
- Advanced configuration options

### Step 3: Configure Basic Project Settings

1. **Project Name**
   - Choose a descriptive name for your project
   - Use clear, searchable naming conventions
   - Example: "Product Demo Video - Q1 2025"

2. **Project Orientation**
   - **Landscape (16:9)**: Best for websites, presentations, web content
   - **Portrait (9:16)**: Ideal for mobile content, vertical displays
   - **Square (1:1)**: Perfect for social media posts, versatile format

3. **Folder Organization** (Advanced Create)
   - Select or create a project folder
   - Organize projects by campaign, client, or content type
   - Use descriptive folder names for better organization

### Step 4: Set Initial Project Configuration

1. **Brand Selection** (if available)
   - Choose an existing brand preset
   - Or use default brand settings
   - This affects video styling, colors, and fonts

2. **Content Goals**
   - Define the purpose of your video content
   - Specify target audience if applicable
   - Set approximate video length preference

### Step 5: Finalize Project Creation

1. **Review Settings**
   - Double-check project name and orientation
   - Verify folder placement
   - Confirm brand selection

2. **Create Project**
   - Click "Create Project" to finalize
   - Wait for project initialization
   - You'll be redirected to the project workspace

## Understanding Project Structure

### Project Components

Once created, your project includes several key tabs:

1. **Prompt Tab**: Where you define video content and requirements
2. **Storyboard Tab**: Visual planning and scene organization
3. **Edit Tab**: Timeline-based editing and sequence management
4. **Voiceover Tab**: Audio generation and management
5. **Render Tab**: Final video output and quality settings

### Understanding System Intelligence

**Automatic Web Search:**
- The system automatically performs web searches when your content requires current information
- No manual control needed - Google API integration provides real-time data
- AI generates optimized search queries for the best results

**Built-in Tools:**
- Calculator and statistical tools automatically activate when needed
- Mathematical operations happen behind the scenes
- No buttons to manage - the system decides when to use these tools

### Cascade Outdated & Stale Markers

**Cascade Outdated Marker (Red indicator):**
- Appears when previous steps have been modified
- Shows you're working with outdated data from earlier workflow stages
- Dependency chain: Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render
- To resolve: Click "Update" button in each affected tab, working through the dependency chain
- **Important**: Import tab changes affect ALL downstream tabs, even though it appears after Prompt visually

**Stale Marker:**
- Appears when you've changed parameters but haven't regenerated content
- Examples: Changing AI settings, toggles, or sliders without re-running generation
- To resolve: Use the chat panel to regenerate content with new parameters
- This is intentional - prevents unwanted automatic regeneration

### Project Settings

Access project settings through the settings menu to modify:
- Project name and description
- Orientation (can be changed later)
- Brand association
- Collaboration permissions
- Export preferences

## Best Practices for Project Creation

### Naming Conventions

**Good Project Names:**
- "Holiday Sale Promo - December 2024"
- "Feature Announcement - Mobile App"
- "Client Testimonial - John Smith"

**Avoid:**
- Generic names like "Video 1" or "Project"
- Special characters that may cause issues
- Extremely long names that get truncated

### Organization Strategy

1. **Use Folders Effectively**
   - Group by campaign or client
   - Separate by content type (promos, tutorials, testimonials)
   - Create date-based folders for time-sensitive content

2. **Consistent Naming**
   - Develop a naming convention for your team
   - Include relevant dates or version numbers
   - Use descriptive keywords for easy searching

### Orientation Guidelines

**Choose Landscape for:**
- YouTube videos
- Website content
- Presentations and webinars
- Detailed product demonstrations

**Choose Portrait for:**
- TikTok and Instagram Stories
- Mobile-first content
- Quick social media posts
- Vertical advertising campaigns

**Choose Square for:**
- Instagram feed posts
- LinkedIn content
- Facebook posts
- Cross-platform social content

## Troubleshooting Common Issues

### Project Creation Errors

**"Failed to create project"**
- Check your organization permissions
- Ensure you haven't reached project limits
- Verify stable internet connection
- Try refreshing the page and attempting again

**"Invalid project name"**
- Remove special characters
- Ensure name isn't too long
- Check for duplicate names in the same folder

### Missing Options

**Can't see brand presets**
- Verify you have access to organization brands
- Check if brands exist in your organization
- Contact organization admin for brand access

**Limited folder options**
- Check your permission level
- Verify organization folder structure
- Request folder creation access if needed
