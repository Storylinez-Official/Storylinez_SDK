# How to Get/Import Stock Media on Storylinez

Learn how to discover, search, and import stock media (videos, images, and audio) into your Storylinez projects.

## System Intelligence Features

StoryLinez includes powerful automatic intelligence features that enhance your stock media discovery:

### Automatic Web Search Integration
- **Google API Integration**: The system automatically searches the web for relevant context about stock media
- **No Manual Control**: This happens automatically without any action required from you
- **Enhanced Discovery**: Helps find better matching stock media based on your project context
- **Background Process**: Web searches happen seamlessly while you browse stock media

### Built-in Tools Activation
- **Calculator & Statistical Tools**: Automatically activated when analyzing stock media
- **Automatic Processing**: These tools work without manual intervention
- **Quality Analysis**: Helps evaluate stock media quality and relevance
- **Smart Recommendations**: Provides intelligent suggestions based on your project needs

*These features work automatically in the background to enhance your stock media selection experience.*

## What is Stock Media?

Stock media on Storylinez includes:
- **Videos**: Professional footage from Pexels and other sources
- **Images**: High-quality photos and graphics  
- **Audio**: Background music and sound effects

## Accessing Stock Media

### Through the Import Tab

1. Open your project and navigate to the **Import** tab
2. Click on the **Stock Media** section
3. Browse the available media or use the search function
4. Filter by media type (videos, images, or audio)

### Using the Advanced Search Feature

1. From the main dashboard, click **Advanced Search**
2. Select your desired media type (video, audio, or image)
3. Enter search terms describing what you need
4. Use filters like:
   - Orientation (landscape/portrait for videos)
   - Color themes
   - Mood or style
   - Duration (for videos and audio)

## Search Methods

### Basic Text Search
- Enter keywords like "business meeting", "nature landscape", or "upbeat music"
- The system searches through AI-analyzed descriptions of media

### Advanced Search Options
- **Color Search**: Find media with specific color palettes
- **Mood Search**: Search by emotional tone (happy, serious, dramatic)
- **Object Search**: Find media containing specific objects or subjects
- **Scene Search**: Locate videos with particular scene types

## Adding Stock Media to Projects

### Individual Items
1. Click on any stock media item to preview it
2. Click the **Add to Project** button
3. Select which project to add it to
4. The media will appear in your project's Import tab

### Bulk Addition
1. Select multiple items using checkboxes
2. Click the **Add Selected to Project** button
3. Choose your target project
4. All selected items will be added at once

## Stock Media in Project Workflow

### In the Import Tab
- View all stock media added to your project
- Preview items before using them
- Remove items you no longer need

### In the Storyboard Tab
- Stock media becomes available for scene assignments
- The AI can automatically select appropriate stock footage
- You can manually assign specific stock media to scenes

### In the Edit Tab
- Replace sequence clips with stock alternatives
- Mix stock media with your uploaded content
- Use stock audio as background music

## Best Practices

### Search Strategy
- Start with broad terms, then narrow down
- Try multiple search approaches for better results
- Use the "similar media" feature to find alternatives

### Quality Considerations
- Preview media before adding to ensure it matches your vision
- Check resolution and quality for your intended use
- Consider the style consistency across your project

### Organization
- Add relevant stock media early in your project planning
- Remove unused media to keep projects organized
- Use descriptive search terms for faster discovery

## Understanding Workflow Dependencies

### Cascade Outdated Markers
When upstream workflow steps change, imported stock media may show red cascade outdated markers. This indicates the media context has changed.

**Dependency Chain:**
Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render

**Important**: Import tab changes affect ALL downstream tabs, even though Import appears after Prompt visually.

**To resolve cascade outdated markers:**
1. Update all previous workflow tabs first
2. Then refresh your stock media in the current tab
3. This ensures your imported media works with the latest project data

### Stale Markers
Appear when you change stock media search or import settings but haven't updated:
- Search parameters
- Filter settings
- Import configurations

**To resolve**: Re-search and re-import stock media with the new settings

## Troubleshooting

### Media Not Loading
- Check your internet connection
- Refresh the page
- Try searching with different terms

### Can't Find Specific Content
- Use broader search terms
- Try searching in different media types
- Contact support for specific media requests

### Adding Media Fails
- Ensure you have sufficient storage quota
- Check project permissions
- Verify your subscription includes stock media access

Stock media greatly expands your creative possibilities and helps create professional-looking content even without extensive media libraries.
