## Understanding the Publishing Workflow

### Pre-Publishing Checklist
Before you publish, ensure your video meets these criteria:
- **Final render completed** and reviewed for quality
- **Content reviewed** for accuracy and brand alignment
- **Legal compliance** checked (copyrights, trademarks, disclosures)
- **Platform requirements** verified for target destinations
- **Metadata prepared** (titles, descriptions, tags, thumbnails)

### Quality Assurance Process
1. **Technical Review**
   - Video resolution and quality
   - Audio levels and clarity
   - Subtitle accuracy and timing
   - Brand element visibility and placement

2. **Content Review**
   - Message clarity and effectiveness
   - Call-to-action prominence
   - Brand guideline compliance
   - Target audience appropriateness

3. **Legal Review**
   - Copyright clearance for all assets
   - Trademark compliance
   - Disclosure requirements
   - Privacy and consent considerations

## Accessing the Publishing Interface

### From the Render Tab
1. Complete your final video render
2. Review the rendered output for quality
3. Click "Publish" or "Export" button
4. Select your publishing destination and settings

### From the Project Dashboard
1. Navigate to your completed project
2. Go to the "Publish" or "Export" section
3. Choose from available rendered versions
4. Configure publishing parameters

## Export Format Options

### Video Formats
- **MP4 (H.264)**: Universal compatibility, standard for most platforms
- **MOV**: High quality, preferred for professional use
- **WebM**: Web-optimized, smaller file sizes
- **AVI**: Uncompressed option for editing workflows

### Resolution Options
- **4K (3840x2160)**: Premium quality for high-end displays
- **1080p (1920x1080)**: Standard HD, widely supported
- **720p (1280x720)**: Good quality with smaller file size
- **Custom Resolutions**: Platform-specific requirements

### Quality Settings
- **Bitrate Control**: Balance quality and file size
- **Frame Rate Options**: 24fps, 30fps, 60fps based on content type
- **Compression Levels**: Optimize for quality vs. file size
- **Audio Quality**: Various bitrates and formats available

## Platform-Specific Publishing

### Video Platform Optimization
**Recommended Settings:**
- Format: MP4 (H.264)
- Resolution: 1080p or 4K
- Frame Rate: 30fps or 60fps
- Audio: AAC, 128 kbps or higher

**Metadata Requirements:**
- Title: Clear, keyword-rich, under 100 characters
- Description: Detailed, include links and timestamps
- Tags: Relevant keywords for discoverability
- Thumbnail: Custom, high-contrast, readable text
- Category: Appropriate category selection

### Social Media Platforms

#### General Social Media
- **Square Format (1:1)**: 1080x1080 for feed posts
- **Vertical Format (9:16)**: 1080x1920 for Stories/Reels
- **Landscape Format (16:9)**: 1920x1080 for standard posts
- **Captions**: Essential for auto-play videos
- **Duration**: 15-60 seconds for optimal engagement

#### Professional Networks
- **Format**: MP4, maximum 2GB file size
- **Duration**: Up to 2 minutes and 20 seconds
- **Resolution**: 1280x720 minimum recommended
- **Captions**: Recommended for accessibility

#### LinkedIn
- **Professional Content**: Longer form acceptable
- **Resolution**: 1920x1080 recommended
- **Duration**: 3 seconds to 30 minutes
- **Format**: MP4 preferred

#### TikTok
- **Vertical Format**: 9:16 aspect ratio mandatory
- **Resolution**: 1080x1920
- **Duration**: 15 seconds to 10 minutes
- **Format**: MP4 with high-quality audio

### Website and Blog Integration
- **Embedded Players**: HTML5 video elements
- **Streaming Options**: For longer content
- **Mobile Optimization**: Responsive design considerations
- **Load Time Optimization**: Compressed formats for web

## Understanding Workflow Dependencies

### Cascade Outdated Markers
When upstream workflow steps change, the Publishing process may show red cascade outdated markers. This indicates earlier content has changed.

**Dependency Chain:**
Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render → Publish

**Important**: Any changes in previous workflow tabs affect the final published content.

**To resolve cascade outdated markers:**
1. Update all previous workflow tabs first
2. Re-render your video with the latest changes
3. Then proceed with publishing the updated content

### Stale Markers
Appear when you change publishing settings but haven't applied them:
- Export quality settings
- Platform-specific configurations
- Metadata or branding elements
- Distribution parameters

**To resolve**: Apply your new publishing settings and re-export if necessary

## Troubleshooting Common Issues

### Export Problems
- **File Size Too Large**: Adjust compression settings or resolution
- **Quality Issues**: Check render settings and source material quality
- **Format Incompatibility**: Verify platform requirements and export settings
- **Processing Errors**: Clear cache and restart export process

### Platform Upload Issues
- **Failed Uploads**: Check internet connection and file format compliance
- **Metadata Rejection**: Verify compliance with platform community guidelines
- **Copyright Claims**: Review and clear any flagged content
- **Technical Restrictions**: Ensure compliance with platform technical requirements

### Performance Issues
- **Low Engagement**: Review content quality and audience targeting
- **Poor Reach**: Optimize metadata and consider promotional strategies
- **Technical Problems**: Address any playback or accessibility issues
- **Brand Inconsistency**: Review and update branding elements
