## Understanding the Prompt Tab Interface

The central text area where you write your prompt:

## Writing Effective Prompts

### Prompt Structure Best Practices

#### 1. Clear Objective Statement
Start with a clear statement of what you want to achieve:
```
Create a 60-second product demonstration video for our new smartphone that highlights three key features: camera quality, battery life, and design aesthetics.
```

#### 2. Target Audience Definition
Specify who you're trying to reach:
```
Target Audience: Tech-savvy millennials aged 25-35 who value both functionality and style in their devices.
```

#### 3. Key Messages and Benefits
Outline the main points you want to communicate:
```
Key Messages:
- Professional-grade camera system with AI-enhanced photography
- All-day battery life that keeps up with busy lifestyles
- Premium design that makes a statement
```

#### 4. Tone and Style Guidelines
Define the personality and feel of your content:
```
Tone: Confident yet approachable, modern and innovative
Style: Clean, minimalist visuals with dynamic transitions
Mood: Energetic and inspiring, showcasing possibilities
```

#### 5. Specific Requirements
Include any must-have elements:
```
Requirements:
- Include actual product footage and close-up shots
- Feature diverse users in real-world scenarios
- End with clear call-to-action for pre-orders
- Ensure accessibility with captions and clear audio
```

### Advanced Prompt Techniques

#### Using Context Layers
Build complexity through layered information:
```
Business Context: Launching a premium smartphone in competitive market
Product Context: High-end device with unique AI photography features
Marketing Context: Pre-launch campaign targeting early adopters
Emotional Context: Excitement about innovation and creative possibilities
```

#### Incorporating Brand Voice
Ensure consistency with your brand personality:
```
Brand Voice Integration:
- Use our established tagline: "Innovation in Your Hands"
- Maintain our signature blue and silver color palette
- Reference our commitment to sustainable technology
- Align with our "premium but accessible" positioning
```

#### Scenario-Based Prompting
Create specific use case scenarios:
```
Scenarios to Include:
1. Professional photographer capturing perfect shots in challenging light
2. Busy parent documenting family moments throughout the day
3. Travel enthusiast sharing experiences with stunning visuals
```

## Understanding Workflow Dependencies

### Cascade Outdated Markers
When upstream workflow steps change, the Prompt tab may show red cascade outdated markers. This indicates project settings have changed.

**Dependency Chain:**
Project Settings → Import → Prompt → Storyboard → Voiceover → Edit → Render

**Important**: Import tab changes affect ALL downstream tabs, even though Import appears after Prompt visually.

**To resolve cascade outdated markers:**
1. Update all previous workflow tabs first (Project Settings, Import)
2. Then click "Update" in the Prompt tab
3. This ensures your prompt works with the latest project configuration

### Stale Markers
Appear when you change prompt settings but haven't regenerated content:
- AI parameters (Temperature, creativity settings)
- Content type selections
- Target audience modifications
- Brand preset changes

**To resolve**: Regenerate content with your updated prompt settings
